# MCP для агентов

Vibefluence отдаёт документацию агентам по протоколу MCP (Streamable HTTP, без сессий) на пути `/mcp` того же сервера. Аутентификации нет, как и у всего сервиса: сервер рассчитан на внутренний контур.

## Подключение

Claude Code:

```bash
claude mcp add --transport http vibefluence http://vibefluence.internal:8080/mcp
```

Любой другой MCP-клиент подключается по адресу `http://<хост>:<порт>/mcp` с транспортом Streamable HTTP.

## Инструменты

| Инструмент | Что делает | Только чтение |
|---|---|---|
| `list_repositories` | Репозитории, ветки, число документов | да |
| `list_documents` | Опубликованные документы репозитория, фильтры по папке и по `type` | да |
| `read_document` | Текст документа в Markdown вместе с front matter и `blobId` | да |
| `search_documents` | Поиск по заголовкам, путям и тексту, все слова обязательны | да |
| `list_drafts` | Черновики на сервере | да |
| `read_draft` | Черновик по пути документа | да |
| `save_draft` | Создать или заменить черновик. В GitLab ничего не уходит | нет |
| `publish_document` | Опубликовать сохранённый черновик через MR | нет, **выключен по умолчанию** |

Ресурсы: шаблон `vibefluence://<repo>/<путь>` отдаёт опубликованный документ как `text/markdown`.

## Правила

- Документы со `status: draft` в front matter, лежащие в репозитории, не видны ни в одном инструменте.
- Правка существующего документа: прочитать `read_document`, изменить текст, вызвать `save_draft` с тем же `path` и `baseBlobId` из ответа. Если файл успел измениться, публикация вернёт конфликт.
- Новый документ: `save_draft` с пустым `baseBlobId`, путь внутри настроенной папки документации (по умолчанию `docs/`), расширение `.md`.
- Записанные агентом черновики видны в веб-интерфейсе в разделе «Черновики», автор помечается как `MCP agent`, если не указан другой.

## Настройка

```yaml
mcp:
  enabled: true        # false убирает эндпоинт /mcp
  allowPublish: false  # true добавляет инструмент publish_document
```

Включайте `allowPublish` только если доверяете всем, кто достаёт сервис по сети: эндпоинт не аутентифицирован, а публикация создаёт и вливает merge request от имени токена бота.
