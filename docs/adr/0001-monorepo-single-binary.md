# 0001. Монорепа и единый бинарник

## Контекст

Бэкенд на Go и фронтенд на Angular разрабатывает одна команда, сервис внутренний, ставится в закрытый контур.

## Решение

Один репозиторий с каталогами `backend/` и `frontend/`. Продакшн-сборка кладёт собранный фронтенд в `backend/internal/web/dist` и встраивает его в Go-бинарник через `embed`. Один процесс, один контейнер, один порт.

## Последствия

- Развёртывание сводится к запуску одного файла или одного образа.
- Версии фронтенда и бэкенда не расходятся.
- Сборка бэкенда без собранного фронтенда работает: каталог `dist` содержит только `.gitkeep`, а сервис отвечает JSON-404 вместо страницы.
- Dev-режим запускает Angular dev-server отдельно с прокси на бэкенд.
