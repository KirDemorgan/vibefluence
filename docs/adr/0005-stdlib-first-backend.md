# 0005. Бэкенд на стандартной библиотеке, минимум зависимостей

## Контекст

Требования: безопасность, оптимизированность, только проверенные библиотеки без экзотики. Сервис маленький: HTTP API, клиент GitLab, индекс в памяти.

## Решение

Опираемся на стандартную библиотеку: `net/http` с маршрутами по методу и шаблону, `log/slog`, `embed`, `testing`. Внешняя зависимость пока одна: разбор YAML (`go.yaml.in/yaml/v3`). Клиент GitLab пишем сами поверх `net/http`: нужно несколько эндпоинтов, а контроль над таймаутами, повторами и ошибками важнее готовой обёртки. Новые зависимости добавляем только с обоснованием.

Качество проверяют `go vet`, `golangci-lint` (включая `gosec`, `errorlint`, `noctx`), `govulncheck` и тесты с `-race`.

## Последствия

- Малая поверхность атаки и простой аудит зависимостей.
- Больше собственного кода там, где обычно берут библиотеку (клиент GitLab).
- Решение пересматривается, если объём клиента или поиска вырастет.
