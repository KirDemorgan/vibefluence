# 0007. MCP для агентов поверх того же сервиса

## Контекст

Агентам нужно читать документацию и предлагать правки. Отдельный сервис означал бы второй индекс, второй деплой и расхождение данных.

## Решение

MCP-сервер на официальном Go SDK работает в том же процессе на пути `/mcp` (Streamable HTTP, без сессий, ответы JSON) и ходит в те же `portal` и индекс, что и REST API. Инструменты чтения доступны всегда. `save_draft` пишет только в серверное хранилище черновиков. `publish_document` по умолчанию выключен (`mcp.allowPublish`), потому что публикация меняет репозиторий. Весь `/mcp` попадает под лимит записи по IP.

## Последствия

- Агент видит ровно то, что видит человек, включая скрытие `status: draft`.
- Аутентификации нет, как и у остального сервиса: включённая публикация доступна любому, кто достучится до порта.
- Пока SDK меняет API, версия закреплена в `go.mod`; обновление требует прогона `internal/app/mcp_test.go` с реальным клиентом.
