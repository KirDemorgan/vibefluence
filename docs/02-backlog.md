# Vibefluence: бэклог (v2)

Статус: план утверждён, реализован по milestone M0–M5 (статусы в конце каждого раздела). Решения и дизайн: [03-decisions.md](03-decisions.md). Анализ конкурентов: [01-research.md](01-research.md).

Приоритеты: P0 без этого продукта нет, P1 нужно для первого релиза, P2 после. Размеры: S до 1 дня, M 2–4 дня, L до 2 недель. Оценки грубые.

## Архитектура

```
+------------------+   REST    +----------------------------------+
| Angular 22 +     +---------->+  Go backend (один бинарник)      |
| Taiga UI 5       |           |   api   index   drafts  publish  |
| (embed в бинарь) |           |   mcp (/mcp)                     |
+------------------+           +--------+------------------+------+
                                        |                  |
 +-------------+  MCP (HTTP)            |                  |
 | AI-агенты   +------------------------+                  |
 +-------------+                                            |
                                              data/drafts/ (файлы)
                                                   |
                                    GitLab API (токен бота)
                                    tree, blobs, commits, MR, merge
```
